## 1. Introduction

Neural style transfer (NST) [1] enables impressive artistic transformations of photographs by combining the content of one image with the artistic style of another. However, when applied to portraits—especially of children—traditional NST methods often distort facial features to the point where individuals become unrecognizable. This poses significant challenges for applications such as children's book illustration, where maintaining facial identity while applying artistic styles is crucial.

**Our Goal:** Develop a fast neural style transfer system that preserves facial identity during stylization, achieving real-time performance while maintaining recognizable facial features.

**Key Challenges:**
1. **Identity preservation:** Traditional style transfer often distorts faces beyond recognition
2. **Ethical concerns:** Using real children's photos raises privacy issues
3. **Speed requirements:** Optimization-based NST is too slow (30-60s per image) for interactive applications

**Our Approach:** We extend the AdaIN (Adaptive Instance Normalization) architecture [3] with a novel face recognition loss function, trained on 100% synthetic faces generated by StyleGAN [8] for ethical compliance. Our method achieves real-time performance (~0.13s per image, 300× faster than optimization-based methods) while preserving facial identity.

## 3. Approach

### 3.1 Model Architecture

Our model consists of three components:

**1. Encoder (Frozen):**
- Pretrained VGG19 network [5]
- Extracts features from relu1_1, relu2_1, relu3_1, relu4_1 layers
- Provides multi-scale feature representations

**2. AdaIN Transform:**
```
AdaIN(f_c, f_s) = σ(f_s) × [(f_c - μ(f_c)) / σ(f_c)] + μ(f_s)
```
where f_c and f_s are content and style features, μ and σ are channel-wise statistics.

**3. Decoder (Trainable):**
- Symmetric architecture with upsampling layers
- Reconstructs stylized image from transformed features
- 3.5M trainable parameters

### 3.2 Loss Function

Our total loss balances three objectives:

```
L_total = L_content + λ_style × L_style + γ × L_identity
```

**Content Loss:**
```
L_content = ||φ(I_g) - φ(I_c)||²
```
Preserves spatial structure using relu4_1 features from VGG19.

**Style Loss:**
```
L_style = Σ_i ||μ(φ_i(I_g)) - μ(φ_i(I_s))||² + ||σ(φ_i(I_g)) - σ(φ_i(I_s))||²
```
Matches mean and standard deviation of features across multiple layers (relu1_1 to relu4_1).

**Identity Loss (Our Contribution):**
```
L_identity = ||ψ(F_g) - ψ(F_c)||²
```
where:
- F_c, F_g are detected face regions in content and generated images
- ψ is a pretrained face recognition model (InceptionResnetV1 from FaceNet [4])
- Embedding dimension: 512
- Computed only when faces are detected in both images

**Face Recognition Pipeline:**
- Detection: MTCNN [7] with min_face_size=40, thresholds=[0.6, 0.7, 0.7]
- Recognition: InceptionResnetV1 pretrained on VGGFace2 [6]
- Similarity metric: Cosine similarity on 512-dimensional embeddings

### 3.3 Training Strategy

**Hyperparameters:**
- Optimizer: Adam with learning rate 1×10⁻⁴
- Batch size: 64 (optimized for NVIDIA A6000 24GB GPU)
- Image size: 256×256 during training
- Content weight (λ_content): 1.0
- Style weight (λ_style): 10.0
- Identity weight (γ): 0.0 (baseline) or 0.1-1000 (identity-preserving, under tuning)

**Training Setup:**
- GPU: NVIDIA RTX 6000 Ada Generation (CUDA 12.1)
- Training time: ~4 minutes per model (20 epochs)
- Data augmentation: None (exhaustive pairing of content × style images)
- Validation: Every epoch on 840 pairs (40 content × 21 styles)

**Identity Weight γ (Completed):**
- Tested: γ ∈ {0, 0.1, 1, 10, 100, 1000, 10000, 100000} (8 orders of magnitude)
- **Optimal:** γ=1000 achieves +2.2% face similarity improvement (0.7623 vs 0.7399 baseline)
- **Key Discovery:** Non-monotonic U-curve relationship
  - γ=0.1-10: Face similarity **drops** below baseline (worse performance)
  - γ=100-1000: Face similarity **rises** above baseline (optimal range)
  - γ>1000: Style collapse, severe quality degradation
- **Insight:** Identity loss must constitute 3-15% of total loss to be effective
- See comprehensive ablation study in `results/tuning/`

## 5. Future Work and Extensions

Our current results are strong, but we have identified several promising directions to make the project more competitive:

### 5.1 Eye-Specific Loss Function (High Priority)

**Motivation:** Eyes are the most critical facial feature for identity perception. Current identity loss treats all facial regions equally.

**Proposed Approach:**
- Extract eye landmarks using MTCNN (provides precise eye coordinates)
- Crop eye regions (e.g., 40×40 patches around each eye)
- Apply **separate identity loss** specifically to eye regions with higher weight:
  ```
  L_total = L_content + λ_style·L_style + γ·L_identity + β·L_eye
  ```
- Expected improvement: +1-2% additional face similarity, especially for difficult styles

**Implementation:** Extend `model_face_utils.py` with eye region extraction and weighted loss

### 5.2 Vision Transformer Backbone (Medium Priority)

**Motivation:** VGG19 (2014) is outdated. Modern Vision Transformers [9] achieve superior feature representations.

**Proposed Approach:**
- Replace VGG19 encoder with **pretrained ViT-B/16** (ImageNet-21k)
- Use multi-head attention features instead of convolutional features
- Adapt AdaIN to work with transformer patch embeddings
- Expected benefits:
  - Better semantic understanding of faces
  - Improved style-content separation
  - Potentially stronger identity preservation

**Challenges:** Higher computational cost, need to adapt AdaIN for non-convolutional features

**Alternative:** Try **Swin Transformer** [10] (hierarchical architecture, more suitable for dense prediction)

### 5.3 Multi-Scale Identity Preservation (High Impact)

**Approach:**
- Apply identity loss at **multiple resolutions** (e.g., 64×64, 128×128, 256×256)
- Coarse scales preserve overall face structure
- Fine scales preserve detailed features (wrinkles, freckles)
- Multi-scale loss:
  ```
  L_identity_multi = Σ_s w_s · ||ψ_s(F_g^s) - ψ_s(F_c^s)||²
  ```

**Expected Improvement:** Stronger identity preservation across different stylization intensities

### 5.4 Human Evaluation Study (Publication-Quality)

**Approach:**
- Recruit 30-50 participants via Amazon Mechanical Turk or Prolific
- A/B testing: baseline vs identity-preserving results
- Metrics: Identity recognition accuracy, stylization quality preference
- Statistical analysis: Paired t-test, Cohen's d effect size

**Why Important:** Human evaluation is gold standard for perceptual tasks, significantly strengthens publication

### 5.5 Additional Competitive Extensions

**Perceptual Identity Loss:**
- Use **intermediate features** from face recognition network, not just final embeddings
- Captures both high-level identity and low-level facial details

**Attention-Guided Stylization:**
- Add attention modules to focus stylization on non-facial regions
- Preserve face regions more aggressively while stylizing background strongly

**Style Interpolation:**
- Enable smooth blending between multiple artistic styles
- Maintain identity consistency across interpolation path

## 6. Technical Challenges and Solutions

**Challenge 1: Face Detection Failures**
- Some stylized images are too distorted for face detection
- **Solution:** Use pre-detection on content images; skip identity loss if detection fails

**Challenge 2: Gradient Flow Through Face Recognition Model**
- Initial implementation had `torch.no_grad()` blocking gradients
- **Solution:** Added `allow_grad` parameter to enable gradient flow during training

**Challenge 3: Loss Balance**
- Identity loss magnitude much smaller than style loss
- **Solution:** Systematic weight tuning with logarithmic spacing (γ = 0.1, 1.0, 10.0, ...)

**Challenge 4: Reproducibility**
- Non-deterministic CUDA operations caused result variation
- **Solution:** Set all random seeds + enable deterministic CUDA mode
